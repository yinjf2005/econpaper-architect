# 附：模板 B / 模板 C 的章节差异

## 模板B · 理论主导型

1. 引言（动机 + 模型概述 + 主要结果预告 + 文献定位）
2. 模型设定（环境设定、主体偏好、技术约束、信息结构）
3. 分析（均衡定义、求解、比较静态分析）
4. 扩展（可选；放松关键假设或引入新维度）
5. 实证含义（可选；从模型推导可检验假说）
6. 结论

> 关键判断标准：模型是否产生了反直觉但逻辑自洽的结论？新预测是否可被实证检验？
> 常见陷阱："为数学而数学"——模型与经济问题脱节。

## 模板C · 理论-实证混合型

1. 引言
2. 理论框架 / 概念框架（简化模型，推导可检验假说）
3. 数据与实证策略
4. 结果
5. 机制分析（用理论框架指导机制检验）
6. 稳健性
7. 结论

> 生命线：理论模型的预测必须与实证设计的因变量、核心解释变量形成可检验的对应关系。
> 两部分过渡：理论部分末尾自然导出假说，实证部分开头重述理论预测。
