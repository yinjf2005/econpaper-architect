# 指引 §四 逻辑推演方式（3 种逻辑方式 × 6 种逻辑样态）

> 保真摘录自《经济论文撰写指引》第四章。含 4.3 适配矩阵、4.4 决策层 L1–L6、4.5 计算机可执行规则。这是 D-8 的裁决依据。

## 四、逻辑推演方式的选项(与3.0模型家族、3.6决策逻辑严格对照的适配矩阵)


### 4.0 先回答一个前置问题：能否做到“计算机可对照选择执行”？

结论：可以，但需要施加结构性约束。
纯粹的自由组合确实会爆炸：3.0中有约40个具体模型，3.6有6层决策，若再乘以逻辑方式（演绎/归纳/溯因）×逻辑样态（链/树/环/网/螺旋/场）×研究目标×数据类型，理论组合数超过10⁴。但关键在于：逻辑推演方式不是自由变量，而是由模型家族的结构特征和研究问题的认识论目标共同决定的。 一旦模型通过3.6的六层决策被确定，逻辑方式的选择空间就从“无限组合”收缩为“2–5个有效候选”。
因此，可行的方案是：建立“模型家族→逻辑方式→逻辑样态”的三级映射矩阵，将组合数从10⁴压缩到约40个有效组合。这一规模完全可由计算机对照执行。

### 4.1 逻辑推演方式的基础类型


#### 4.1.1 演绎逻辑（Deductive Logic）

方向： 一般性前提 → 特定结论。
核心结构： 大前提（理论假设）→ 小前提（情境条件）→ 结论（可检验命题或均衡结果）。
适用条件： 前提为真且推理有效时，结论必然为真。适用于理论模型、结构模型和一切从假设出发推导均衡结果的研究。
在经济学中的典型形态： 从效用最大化、利润最大化、市场出清等公理出发，推导出比较静态结果或福利定理。
适配模型家族： 结构模型与估计家族（3.0.2）、部分时间序列模型（DSGE、SVAR）、机制设计。

#### 4.1.2 归纳逻辑（Inductive Logic）

方向： 特定观察 → 一般性判断。
核心结构： 数据中的规律 → 统计推断 → 一般性因果或相关关系。
适用条件： 观察样本具有代表性，推断方法具有统计有效性。结论是概率性的而非确定性的。
在经济学中的典型形态： 从面板数据、实验数据或自然实验数据中估计处理效应，归纳出“X导致Y”的一般性判断。
适配模型家族： 因果识别家族（3.0.1）、机器学习与因果推断交叉家族（3.0.4）、面板数据模型。

#### 4.1.3 溯因逻辑（Abductive Logic）

方向： 观察到的现象 → 最可能的生成机制。
核心结构： 观察到一个令人困惑的现象 → 提出多个候选机制 → 排除竞争性解释 → 保留最佳解释。
适用条件： 现象已知但机制未知；存在多个理论上可能的解释；需要通过理论建模或实证检验来区分竞争性机制。
在经济学中的典型形态： 从实证中发现的“反常”模式出发，构建理论模型来解释它；或用机制检验来区分多个竞争性假说。
适配模型家族： 理论-实证混合型论文（模板C）、合成控制法、ABM、系统动力学。

### 4.2 逻辑样态的类型

逻辑样态（logical topology）指论证的结构形态，而非推理方向。同一推理方向可以呈现不同的样态。以下六种样态按结构复杂度递增排列：链→树→环→网→螺旋→场。

#### 4.2.1 逻辑链（Chain）

结构： A → B → C → D → 结论。
特征： 线性、单向、无分支。每一步的输出是下一步的输入。
典型场景：
RCT：随机化 → 处理分配 → 结果测量 → 效应估计
DID：平行趋势 → 双重差分 → ATT估计 → 推断
IV：相关性 → 第一阶段 → 第二阶段 → 因果效应
VAR：冲击识别 → 脉冲响应 → 动态路径 → 结构性解释
优点： 清晰、可复现、易于计算机执行。缺点： 无法处理多机制并存或反馈回路。

#### 4.2.2 逻辑树（Tree）

结构： 根节点 → 多个分支 → 每个分支产生不同结论。
特征： 分叉、多层次、条件依赖。不同分支对应不同的假设或情境。
典型场景：
结构模型：多个均衡分支（高均衡/低均衡）
DSGE：不同冲击的脉冲响应分支（货币政策冲击/财政冲击/技术冲击）
博弈论：子博弈精炼均衡的多重性
机制设计：最优机制在不同信息结构下的特征差异
因果森林：递归划分产生的异质性处理效应分支
异质性分析：不同子样本的差异化效应
优点： 能刻画条件性和异质性。缺点： 分支过多时解释力下降。

#### 4.2.3 逻辑环（Loop）

结构： A → B → C → A（反馈回路）。
特征： 循环、反馈、动态调整。系统的输出反过来影响输入。
典型场景：
DSGE：利率 → 投资 → 产出 → 通胀 → 利率
ABM：主体行为 → 市场结果 → 主体预期更新 → 主体行为
系统动力学：存量 → 流量 → 存量
动态面板：滞后因变量 → 当前因变量 → 未来滞后因变量
动态离散选择：当前决策 → 状态转移 → 未来决策
优点： 能刻画动态反馈和路径依赖。缺点： 均衡的多重性和稳定性分析复杂。

#### 4.2.4 逻辑网（Network）

结构： 多节点、多连接、多路径的拓扑结构。节点之间并非简单的线性顺序或树形分支，而是存在交叉连接、多重路径、冗余链路。A可以同时影响B和C，B和C又共同影响D，D反过来通过另一条路径影响A。
特征：
多对多映射： 多个原因共同作用于多个结果，不存在单一的“主路径”。
路径冗余： 同一结论可以通过多条不同的论证路径到达，增强了稳健性但增加了识别难度。
局部与全局并存： 网络中的某些子图可以独立分析（局部逻辑），但整体行为需要全局视角。
模块化： 网络可以分解为多个模块，模块内部高内聚、模块之间低耦合。
与逻辑环的区别： 环是单一反馈回路，网是多个回路的交织。环的反馈是序列性的，网的反馈是并行性和分布性的。
典型场景：
多机制并存的因果识别： 一个处理变量通过多个中介变量影响结果，且中介变量之间存在相互作用。例如，教育政策通过“提高认知技能”“改变社会网络”“信号效应”三条路径影响收入，三条路径之间存在互补或替代关系。
结构性模型的参数网络： BLP模型中，需求参数、成本参数、均衡价格、市场份额之间的相互依赖关系构成一个参数网络。改变任何一个参数都会通过多条路径影响其他参数。
ABM中的主体互动网络： 主体之间的交易关系、信息传播关系、信任关系构成多层网络，宏观涌现现象是这些网络交互作用的产物。
投入产出网络： CGE模型中的部门间投入产出关系本质上是一个加权有向网络，一个部门的需求冲击通过多条产业链路径传导至整个经济系统。
文献网络与知识图谱： 一篇论文的理论贡献通过多条路径与现有文献相连——概念借用、方法继承、结论对话、数据扩展——这些路径共同构成论文在学术网络中的位置。
关键理论来源：
Jackson (2008), Social and Economic Networks——经济网络的理论基础。
Acemoglu, Carvalho, Ozdaglar & Tahbaz-Salehi (2012), “The Network Origins of Aggregate Fluctuations,” Econometrica——网络结构与宏观波动。
Barabási (2016), Network Science——网络科学的综合教材。
Bramoullé, Djebbari & Fortin (2009), “Identification of Peer Effects through Social Networks,” Journal of Econometrics——网络中的识别问题。
实操注意：
逻辑网的论证需要明确节点定义（什么是论据单元）和边定义（论据之间的关系类型：因果、逻辑蕴含、统计相关、机制互补等）。
网络分析中的中心性指标（度中心性、介数中心性、特征向量中心性）可用于识别论证中的“关键节点”——哪些论据是承重的，哪些是装饰性的。
逻辑网的脆弱性分析：如果移除某个关键节点（如核心假设），整个论证网络是否崩溃？这对应稳健性检验中的“关键假设敏感性分析”。
网络的可视化（如DAG、路径图、热力图）是呈现逻辑网的标准工具。

#### 4.2.5 逻辑螺旋（Spiral）

结构： A → B → C → A‘ → B’ → C‘ → A’‘ → …（递归上升）。
特征：
递归性： 论证在更高层次上回到先前的主题，但并非简单重复，而是带着新的信息、新的约束或新的综合。
层次跃迁： 每一次螺旋循环都将论证推进到一个更高的抽象层次或更具体的经验层次。
辩证结构： 正题→反题→合题→新的正题。每一个“合题”成为下一轮循环的“正题”。
路径依赖： 螺旋的每一圈都受前一圈的约束，不可跳跃。
与逻辑环的区别： 环是闭合的、回归原点的；螺旋是开放的、上升的。环追求均衡和稳态，螺旋追求演进和深化。
与逻辑树的区别： 树是空间性的分支，螺旋是时间性的递归。树的分支可以并行，螺旋的层次必须顺序经过。
典型场景：
理论-实证的迭代对话： 这是逻辑螺旋最经典的应用。第一圈：从理论出发推导假说→用数据检验→发现理论预测与数据不符。第二圈：修正理论假设→重新推导→用新的数据或新的方法检验→发现新的不符。第三圈：进一步修正→…→最终形成对现象的更深刻理解。每一圈都不是简单的重复，而是理论精确性和经验拟合度的同步提升。
DSGE模型的估计-评估-修正循环： 构建基准模型→贝叶斯估计→脉冲响应评估→发现某些矩拟合不佳→引入金融摩擦/异质性/非线性→重新估计→重新评估→…。Smets & Wouters (2003, 2007) 的模型演进就是典型的螺旋过程。
ABM的校准-模拟-验证循环： 设定微观行为规则→模拟宏观涌现→与典型事实比较→发现偏差→修正行为规则→重新模拟→…。每一轮循环都使模型的微观基础更合理、宏观拟合更精确。
机制设计的实验检验循环： 设计最优机制→实验室实验检验→发现行为偏差→修正理性假设→设计新机制→再实验→…。行为契约理论的兴起正是这一螺旋的产物。
论文自身的写作螺旋： 初稿→审稿意见→修改→再投稿→再审稿→…。每一轮审稿意见都迫使作者在更高层次上重新审视论证结构。
关键理论来源：
Hegel (1812/1969), Science of Logic——辩证法和螺旋上升的哲学基础。
Popper (1959), The Logic of Scientific Discovery——猜想与反驳的循环。
Lakatos (1976), Proofs and Refutations——数学发现的螺旋结构。
Kuhn (1962), The Structure of Scientific Revolutions——范式转换中的螺旋式演进。
Box (1976), “Science and Statistics,” JASA——所有模型都是错的，但有些是有用的（迭代建模的哲学）。
实操注意：
逻辑螺旋的论文写作需要明确标注循环的层次。例如：“在第一轮分析中，我们假设X；在发现Y之后，我们在第二轮中放松了该假设。”
每一圈的“增量贡献”必须清晰： 螺旋不是重复，每一圈必须有新的信息、新的约束或新的综合。否则就沦为逻辑环。
螺旋的终止条件： 何时停止迭代？当理论预测与经验证据的差距缩小到可接受范围，或当新一轮修正不再产生实质性变化时。
螺旋的呈现方式： 时间线图、阶段图、层次图。在论文中，通常以“基准模型→扩展模型→进一步扩展”的结构呈现。

#### 4.2.6 逻辑场（Field）

结构： 不是一个离散的节点-边结构，而是一个连续的、分布式的、同时作用的逻辑空间。多个逻辑关系并非呈现为离散的步骤或连接，而是作为同一概念空间内连续或重叠的场域同时共存。
特征：
同时性： 所有逻辑关系同时存在、同时作用，不存在时间上的先后顺序。不同于链、树、环、网中的“依次经过”或“逐层展开”，场中的逻辑关系是共时的。
连续性： 逻辑关系不是“有”或“无”的二值关系，而是强度可变的连续统。某个机制的作用强度从0到1连续变化，而非“存在/不存在”。
梯度性： 场的不同区域有不同的“逻辑势能”——某些区域论证密集、逻辑张力高，某些区域论证稀疏、逻辑张力低。
叠加性： 多个逻辑场可以叠加，产生干涉和共振。多个机制同时作用时，总效应不是各机制效应的简单加总，而是存在交互和涌现。
整体性： 场的性质不能通过孤立分析其局部来理解。局部逻辑只有在场的整体结构中才有意义。
与逻辑网的区别： 网有离散的节点和边，场没有明确的边界和节点。网可以通过图论分析，场需要连续性数学（微分方程、场论、拓扑学）来描述。网的连接是可数的，场的“连接”是不可数的连续分布。
典型场景：
一般均衡的“场”结构： 瓦尔拉斯一般均衡本质上是一个逻辑场——所有价格、所有数量、所有主体的最优化决策同时决定、同时均衡。没有任何一个价格是“先决定”的，没有任何一个市场是“先出清”的。所有市场的同时出清构成一个连续的、分布式的逻辑场。这正是为什么一般均衡的存在性证明需要不动点定理——不动点定理是描述“场”的数学工具。
DSGE模型中的“状态空间”： DSGE模型的解可以表示为一个状态空间中的政策函数，其中所有状态变量和控制变量同时决定。脉冲响应函数描述的是冲击如何在状态空间中传播——这是一种“场”的传播，而非“链”的传递。
异质性处理效应的“效应场”： 在因果森林或元学习器中，CATE是协变量的连续函数。不同协变量取值下的处理效应构成一个“效应场”——效应随协变量平滑变化，不存在离散的“处理组/对照组”二分。估计CATE就是估计这个场的形状。
经济地理学中的“势场”： 克鲁格曼的新经济地理学模型中，企业和工人的区位选择构成一个“势场”——每个地点的吸引力取决于所有其他地点的选择，同时决定、同时均衡。
社会网络的“影响力场”： 在一个社交网络中，每个个体的行为取决于其邻居的行为，而邻居的行为又取决于邻居的邻居……这种同时性的相互依赖构成一个“影响力场”。识别社会网络中的因果效应之所以困难，正是因为这种“场”结构无法通过简单的“链”或“树”来分解。
文献计量中的“知识场”： 一个研究领域的概念、方法、数据、结论构成一个知识场。一篇新论文的贡献不是通过某一条“链”与现有文献相连，而是通过其在知识场中的位置——它与哪些概念相邻、与哪些方法共振、与哪些结论对话。
关键理论来源：
Debreu (1959), Theory of Value——一般均衡的存在性证明（不动点定理）。
Mas-Colell, Whinston & Green (1995), Microeconomic Theory——一般均衡的场论基础。
Krugman (1991), “Increasing Returns and Economic Geography,” Journal of Political Economy——经济地理中的势场。
Wager & Athey (2018), JASA——CATE作为连续函数（效应场）的估计。
Manski (1993), “Identification of Endogenous Social Effects,” Review of Economic Studies——社会网络中的“反射问题”（场的识别困难）。
Bourdieu (1984), Distinction——社会学中的“场”概念（虽非经济学，但对经济社会学有深远影响）。
实操注意：
逻辑场的论证需要明确场的维度：场由哪些维度构成？每个维度的取值范围是什么？
场的可视化： 热力图、等高线图、向量场图、三维曲面图是呈现逻辑场的标准工具。
场的识别策略： 场的识别通常需要排除性约束或函数形式假设。例如，在识别社会网络效应时，需要假设“邻居的邻居”不直接影响自身（排除性约束），或假设效应随距离指数衰减（函数形式）。
场的计算： 场的估计通常涉及高维非参数方法、核平滑、样条回归、高斯过程回归等。计算复杂度显著高于链/树/环/网。
场的解释： 场的“梯度”和“曲率”是有经济含义的——梯度表示效应随协变量变化的速率，曲率表示效应的非线性程度。

#### 4.2.7 六种逻辑样态的对比


| 样态 | 结构 | 时间性 | 分支性 | 反馈性 | 连续性 | 典型数学工具 |
|---|---|---|---|---|---|---|
| 链 | 线性序列 | 顺序 | 无 | 无 | 离散 | 代数、递推 |
| 树 | 层级分支 | 顺序/并行 | 有 | 无 | 离散 | 图论、递归 |
| 环 | 单一回路 | 循环 | 无 | 有 | 离散 | 动力系统、不动点 |
| 网 | 多重连接 | 并行 | 多分支 | 多回路 | 离散+连续 | 图论、网络科学 |
| 螺旋 | 递归上升 | 层级递归 | 层次性 | 有（上升） | 离散+连续 | 迭代、层次建模 |
| 场 | 连续分布 | 同时 | 无分支 | 分布式 | 连续 | 场论、微分方程、拓扑 |


### 4.3 模型家族与逻辑方式的适配矩阵

以下矩阵将3.0的五个模型家族与逻辑方式（演绎/归纳/溯因）×逻辑样态（链/树/环/网/螺旋/场）进行对应。

#### 4.3.1 因果识别家族（3.0.1）


| 具体模型 | 主导逻辑方式 | 主导逻辑样态 | 辅助样态 | 适配组合 | 不适配组合 | 原因 |
|---|---|---|---|---|---|---|
| RCT | 归纳 | 链 | — | 归纳+链 | 演绎+场 | RCT是从随机化到效应估计的单向推断 |
| 自然实验 | 归纳 | 链 | 树 | 归纳+链 | 演绎+环 | 外生冲击的识别是单向的 |
| 传统TWFE DID | 归纳 | 链 | — | 归纳+链 | 溯因+场 | 平行趋势→双重差分→ATT是线性链条 |
| 交叠DID稳健估计 | 归纳 | 树 | 网 | 归纳+树 | 演绎+链 | 异质性处理效应需要按组别-时期分支；多个异质性来源可构成网 |
| 合成DID | 溯因+归纳 | 链 | 网 | 溯因+链 | 演绎+环 | 从案例出发构建反事实；多案例时可构成网 |
| IV | 归纳 | 链 | 网 | 归纳+链 | 溯因+树 | 相关性→排他性→2SLS是标准链条；多工具时可构成网 |
| RDD | 归纳 | 链 | 树 | 归纳+链 | 演绎+环 | 断点两侧的局部比较是单向的；多断点时可构成树 |
| PSM | 归纳 | 链 | 网 | 归纳+链 | 演绎+树 | 匹配→平衡→效应估计是线性流程；多匹配算法可构成网 |
| DR | 归纳 | 链 | — | 归纳+链 | 溯因+环 | 双稳健估计是单一方程框架 |
| 事件研究法 | 归纳 | 链+树 | 网 | 归纳+链（主效应）；归纳+树（异质性） | 演绎+环 | 事件前后的动态效应本质是链；多事件可构成网 |
| SCM | 溯因 | 链+树 | 网 | 溯因+链（单案例）；溯因+树（多案例） | 演绎+环 | 合成对照的构建是溯因的；多donor可构成网 |
| 正则化SCM | 溯因 | 链 | — | 溯因+链 | 归纳+树 | 权重优化是单向的 |
| 贝叶斯SCM | 溯因+归纳 | 树 | 网 | 溯因+树 | 演绎+链 | 先验+后验的分支结构；多处理单位可构成网 |

关键判断： 因果识别家族整体上以归纳逻辑为主导，逻辑样态以链为主，树和网为辅。逻辑螺旋和逻辑场在此家族中极少出现——因果识别追求的是“干净的识别”，而非“递归的深化”或“同时的均衡”。

#### 4.3.2 结构模型与估计家族（3.0.2）


| 具体模型 | 主导逻辑方式 | 主导逻辑样态 | 辅助样态 | 适配组合 | 不适配组合 | 原因 |
|---|---|---|---|---|---|---|
| BLP | 演绎 | 树 | 网、场 | 演绎+树 | 归纳+链 | 从随机系数Logit出发，推导需求弹性和均衡价格，多产品分支；参数间相互依赖可构成网；均衡价格同时决定可构成场 |
| 动态离散选择 | 演绎 | 环 | 螺旋 | 演绎+环 | 归纳+链 | 跨期决策的反馈回路是核心特征；CCP两步法可呈现螺旋 |
| CGE | 演绎 | 树+环 | 网、场 | 演绎+树（部门分支）；演绎+环（反馈回路） | 归纳+链 | 多部门一般均衡同时具有分支和反馈；部门间投入产出构成网；所有市场同时出清构成场 |
| DSGE | 演绎 | 环+树 | 螺旋、场 | 演绎+环（动态反馈）；演绎+树（冲击分支） | 归纳+链 | 动态随机一般均衡的核心是反馈回路和脉冲响应分支；估计-评估-修正循环构成螺旋；状态空间构成场 |
| 博弈论 | 演绎 | 树 | 网 | 演绎+树 | 归纳+环 | 子博弈精炼均衡本质是树形结构；多玩家互动可构成网 |
| 机制设计 | 演绎 | 树 | 螺旋 | 演绎+树 | 归纳+链 | 最优机制的特征在不同信息结构下分支；设计-实验-修正循环构成螺旋 |
| 动态优化 | 演绎 | 环 | 场 | 演绎+环 | 归纳+树 | 跨期最优化的欧拉方程是反馈结构；连续时间最优控制可构成场 |
| 信息经济学 | 演绎 | 树 | 网 | 演绎+树 | 归纳+环 | 不同类型/信号下的均衡分支；多信号交互可构成网 |

关键判断： 结构模型家族整体上以演绎逻辑为主导，逻辑样态以树和环为主，螺旋和场在动态模型中作为辅助样态出现。场的出现频率高于因果识别家族，但低于仿真家族。

| 具体模型 | 主导逻辑方式 | 主导逻辑样态 | 辅助样态 | 适配组合 | 不适配组合 | 原因 |

#### 4.5.1 决策规则的形式化

[python 代码如下]
def select_logic(model_family, research_goal, identification_source,
data_type, inference_target, key_assumption_holds,
complexity_level="standard"):
"""
输入：来自3.6六层决策的模型选择结果
输出：(logic_mode, logic_topology, auxiliary_topologies, logic_chain_description)
complexity_level: "standard"（默认，最多两个辅助样态）
"complex"（允许全部辅助样态）
"minimal"（仅主导样态）
"""
# L1: 研究目标决定逻辑方式的主类型
if research_goal == "causal_effect":
logic_mode = "inductive"
logic_topology = "chain"
auxiliary = ["tree", "network"]
elif research_goal == "structural_parameter":
logic_mode = "deductive"
logic_topology = "tree" if model_family != "dynamic" else "loop"
auxiliary = ["network", "spiral", "field"]
elif research_goal == "dynamic_path":
logic_mode = "inductive+deductive"
logic_topology = "loop"
auxiliary = ["network", "spiral", "field"]
elif research_goal == "heterogeneous_effect":
logic_mode = "inductive"
logic_topology = "tree"
auxiliary = ["network", "field"]
elif research_goal == "emergence":
logic_mode = "abductive"
logic_topology = "loop"
auxiliary = ["network", "spiral", "field"]
elif research_goal == "institution_design":
logic_mode = "deductive"
logic_topology = "tree"
auxiliary = ["spiral"]
# L2: 识别来源修正逻辑样态
if identification_source == "single_unit":
logic_mode = "abductive"
logic_topology = "chain"
auxiliary = ["network"]
elif identification_source == "threshold":
logic_topology = "chain"
auxiliary = ["tree"]
elif identification_source == "equilibrium":
logic_topology = "tree" if logic_topology != "loop" else "loop"
auxiliary = ["network", "spiral", "field"]
# L3: 数据条件修正逻辑样态
if data_type == "high_dimensional":
logic_topology = "tree"
auxiliary = ["network", "field"]
elif data_type == "time_series":
logic_topology = "loop"
auxiliary = ["network", "field"]
elif data_type == "network_data":
logic_topology = "network"
auxiliary = ["field"]
elif data_type == "spatial_data":
logic_topology = "field"
auxiliary = ["network"]
# L4: 推断目标修正
if inference_target == "CATE":
logic_topology = "tree"
auxiliary = ["network", "field"]
elif inference_target == "IRF":
logic_topology = "loop"
auxiliary = ["network", "field"]
elif inference_target == "welfare":
logic_topology = "tree"
auxiliary = ["network", "field"]
# L5: 假设不成立时的逻辑转换
if not key_assumption_holds:
if key_assumption_holds == "parallel_trends":
logic_topology = "tree"
auxiliary = ["network"]
elif key_assumption_holds == "exclusion":
logic_mode = "deductive"
logic_topology = "tree"
auxiliary = ["network", "field"]
elif key_assumption_holds == "CIA":
logic_topology = "tree"
auxiliary = ["network"]
elif key_assumption_holds == "equilibrium":
logic_mode = "abductive"
logic_topology = "loop"
auxiliary = ["network", "spiral", "field"]
# L6: 稳健性检验的逻辑方式
robustness_logic = {
"TWFE_DID": ("inductive", "tree", ["network"]),
"IV": ("inductive", "chain", ["network"]),
"RDD": ("inductive", "chain", []),
"PSM": ("inductive", "tree", ["network"]),
"SCM": ("abductive", "tree", ["network"]),
"DSGE": ("deductive", "tree", ["spiral", "field"]),
"VAR": ("inductive", "loop", ["network"]),
"ABM": ("abductive", "tree", ["network", "spiral", "field"])
}
# 根据complexity_level裁剪辅助样态
if complexity_level == "minimal":
auxiliary = []
elif complexity_level == "standard":
auxiliary = auxiliary[:2]
return {
"logic_mode": logic_mode,
"logic_topology": logic_topology,
"auxiliary_topologies": auxiliary,
"robustness_logic": robustness_logic.get(model_family, None),
"logic_chain": generate_logic_chain(logic_mode, logic_topology, auxiliary)
}

#### 4.5.2 逻辑链的自动生成规则


| 逻辑方式 | 主导样态 | 辅助样态 | 自动生成的逻辑链 |
|---|---|---|---|

#### 4.5.3 有效组合总数

|---|---|---|---|---|
| 因果识别 | 13 | 20 | 28 | 链为主，树/网为辅 |
| 结构模型 | 8 | 18 | 32 | 树/环为主，网/螺旋/场为辅 |
| 时间序列/面板 | 5 | 10 | 16 | 链/环为主，网/场为辅 |
| ML因果 | 3 | 8 | 12 | 链/树为主，网/场为辅 |

结论： 标准复杂度下有效组合数约为68个，全复杂度下约为112个，完全可由计算机对照执行。关键在于先通过3.6确定模型，再通过4.3的适配矩阵确定逻辑方式，而非同时搜索所有组合。complexity_level参数允许研究者根据论文篇幅和论证需要，灵活控制辅助样态的数量。

### 4.6 局限性说明

第一，逻辑方式并非总是排他的。 许多高质量论文同时使用多种逻辑方式。例如，一篇DID论文可能以归纳逻辑为主，但在机制分析部分转向溯因逻辑；一篇DSGE论文可能以演绎逻辑为主，但在参数校准部分使用归纳逻辑。因此，计算机执行时应允许“主逻辑+辅逻辑”的组合，而非强制单选。
第二，逻辑样态可能存在嵌套。 一个逻辑树的分支内部可能包含逻辑链；一个逻辑环的某个节点可能展开为逻辑树；一个逻辑网的某个子图可能表现为逻辑螺旋；一个逻辑场的局部可能呈现逻辑网的离散结构。因此，逻辑样态的标注应视为“主导样态”，而非“唯一析取”。六种样态之间存在嵌套关系：链⊂树⊂网⊂场，环⊂网⊂场，螺旋⊂网⊂场。
第三，溯因逻辑的形式化程度最低。 演绎逻辑和归纳逻辑都有成熟的数学形式化（数理逻辑、统计推断），而溯因逻辑的形式化仍在发展中。这意味着计算机执行时，溯因逻辑的自动生成最为困难，需要更多的人工干预。
第四，螺旋和场的计算复杂度最高。 螺旋需要追踪多轮迭代的增量信息，场需要高维非参数估计。在标准复杂度的论文中，螺旋和场通常作为辅助样态出现，而非主导样态。只有在专门的方法论论文或复杂性经济学论文中，螺旋和场才作为主导样态。
第五，研究创新可能突破现有映射。 上述矩阵基于现有文献的归纳，但真正有创造力的研究可能故意选择“不适配”的逻辑方式，以产生新的洞见。因此，计算机执行应作为“默认建议”，而非“强制约束”。
第六，组合数虽可控，但语义复杂度不可约。 68–112个有效组合在数量上可管理，但每个组合的逻辑链描述、前提条件、论证结构仍需人工精心设计。计算机可以辅助选择，但不能替代论证。特别是逻辑网、逻辑螺旋和逻辑场，其语义复杂度远高于逻辑链和逻辑树，需要研究者在计算机辅助的基础上进行深度的学术判断。
第七，六种样态的认识论地位不同。 链和树是“论证结构”，环和网是“系统结构”，螺旋是“演进结构”，场是“均衡结构”。它们回答的是不同层面的问题：链/树回答“如何论证”，环/网回答“如何互动”，螺旋回答“如何演进”，场回答“如何同时决定”。选择哪种样态，本质上取决于研究者对经济现象的本体论假设——经济世界是线性的、分支的、循环的、网络的、演进的，还是同时均衡的？
