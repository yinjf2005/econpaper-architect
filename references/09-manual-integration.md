## 8.1 必须参与的Skill


### Skill 1：结构化对话管理

接口： conversation_state，记录当前阶段、已确认信息、待确认信息。
调用时机： 每轮对话开始和结束。
异常处理： 若用户跳步，提示“请先完成上一阶段”。
数据格式：
json
{
"stage": "S5",
"confirmed": {"D-1": "模板A", "D-2": "因果识别家族"},
"pending": ["D-3", "D-4"],
"user_preferences": {"language": "中文", "format": "Markdown+LaTeX"}
}

### Skill 2：决策树/规则引擎

接口： select_model(research_goal, identification_source, data_type, inference_target, assumptions)。
调用时机： S5逐项决策阶段。
输出： 模型推荐 + 依据 + 替代方案。
异常处理： 若条件不足，返回“需补充信息”。

### Skill 3：文档生成

接口： generate_section(section_type, content_spec, format)。
调用时机： S7逐节生成。
输出： Markdown/LaTeX文本。
异常处理： 若内容不足，返回“需补充信息”。

### Skill 4：公式渲染

接口： render_latex(latex_string, output_format)。
调用时机： 生成含公式的节。
输出： MathJax/KaTeX/LaTeX/OMML。
异常处理： 若语法错误，返回错误位置和修正建议。

## 8.2 建议参与的Skill


### Skill 5：数据可视化

接口： generate_chart(chart_type, data, style)。
调用时机： S7生成结果节。
输出： Python/Matplotlib代码 + 图片占位符。
异常处理： 若无数据，生成模拟数据并标注。

### Skill 6：文献检索/引用管理

接口： search_literature(keywords, field, years)。
调用时机： S7生成文献综述。
输出： BibTeX + 摘要。
异常处理： 若无法检索，提示用户手动提供。

### Skill 7：表格生成

接口： generate_table(table_type, data, format)。
调用时机： S7生成数据/结果节。
输出： Markdown/LaTeX三线表。
异常处理： 若无数据，生成占位表。

## 8.3 可选参与的Skill


### Skill 8：代码生成/执行

接口： generate_code(method, data_spec, language)。
调用时机： S7生成实证策略/结果节。
输出： Stata/R/Python代码。
异常处理： 若无法执行，提供代码+说明。

### Skill 9：排版美化

接口： apply_style(document, style_spec)。
调用时机： S8整合格式。
输出： 格式化文档。
异常处理： 若样式冲突，提示用户选择。

### Skill 10：多轮迭代管理

接口： track_versions(document, changes)。
调用时机： S9迭代。
输出： 版本历史 + 修改记录。
异常处理： 若版本冲突，提示用户合并。

# 第九部分：用户使用手册


## 9.1 如何开始

将第一部分（系统提示词）复制到workbuddy的系统提示词配置中。
将第二部分至第八部分作为知识库或规则文件上传。
启动对话，输入“开始”或“我想写一篇经济学论文”。

## 9.2 如何与Agent有效沟通

原则一：先给研究问题，再给资料。
好的开场：“我想研究最低工资对青年就业的影响，我有省级面板数据。”
不好的开场：“帮我写一篇论文。”
原则二：明确你的决策偏好。
“模板选择我听你的推荐。”
“模型选择我要自己决定。”
“格式和排版你自主处理。”
原则三：及时确认或否决。
“D-3我确认。”
“D-4我不同意，我想用IV而不是DID。”
原则四：提供反馈要具体。
好的反馈：“引言第二段太长，请压缩到200字。”
不好的反馈：“引言不好。”
原则五：善用“暂停”和“跳过”。
“暂停，我需要补充数据。”
“跳过文献综述，先写实证部分。”

## 9.3 如何检查Agent的输出

检查清单：
决策是否有指引依据？（看“依据指引”标注）
模拟数据是否标注？（看“模拟数据”标注）
公式是否正确？（看渲染效果）
表格是否三线表？（看格式）
参考文献是否完整？（看引用对应）
逻辑是否自洽？（看逻辑链描述）

## 9.4 如何迭代

迭代流程：
阅读Agent输出。
标记需要修改的部分。
给出具体修改意见。
Agent修改后重新确认。
重复直到满意。
迭代终止：
你说“终稿”。
自检清单全部通过。
连续两轮无修改。

## 9.5 常见问题

Q：Agent能替我决定研究问题吗？
A：不能。研究问题是A类决策，必须由你提供。Agent可以给选题建议，但最终由你拍板。
Q：Agent能生成真实数据吗？
A：不能。Agent只能生成模拟数据，并明确标注。真实数据必须由你提供。
Q：Agent能保证论文发表吗？
A：不能。Agent是写作辅助工具，不保证学术质量或发表结果。
Q：Agent能处理多语言吗？
A：能。Agent支持中文和英文写作，可根据目标期刊自动切换。
Q：Agent能生成图表吗？
A：能。Agent可生成图表代码和占位符，但需要你提供数据或授权模拟数据。
Q：Agent能执行回归分析吗？
A：视配置而定。若集成了代码执行Skill，Agent可生成并执行Stata/R/Python代码。
